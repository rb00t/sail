Search, stream, and download torrents entirely from the macOS terminal.

curl -fsSL https://raw.githubusercontent.com/rb00t/sail/main/install.sh | bash

macOS only. The installer adds Homebrew, fzf, webtorrent and IINA.

Thirteen sources, one search.

Every enabled source is asked at once. One that has not answered in six seconds is dropped, never waited on.

Nothing left behind.

Quit the player and the temp video goes. Downloads land in ~/Downloads/torrents.

Only the episodes you pick

Tab toggles files in a season pack; ctrl-a takes all.

Subtitles ride along

When a release carries subtitles, the English one attaches automatically.

Five minutes of search cache

Repeated queries skip the network. Video is never cached.

Run it twice.

First run installs, second upgrades in place. It sets up its own dependencies.

curl -fsSL https://raw.githubusercontent.com/rb00t/sail/main/install.sh | bash

Add --dry-run to print every change and write nothing. Read the installer.
